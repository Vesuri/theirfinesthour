 Features:
 ---------
 Hard disk installation, manual protection removed, Mission Builder support,
 and a choice of classic, NewIcon and ColorIcon game icons.

 Select options in the WHDLoad startup window or use icon tooltypes:
 - CUSTOM1=1: start the Mission Builder.
 - CUSTOM2=1: enable Enhanced framerate (set in the supplied game icons).
   Disable this option to use the original game mode.
 - CUSTOM3: mouse sensitivity with Enhanced framerate enabled:
   0 or unset = 2x, 1 = 1x, 2 = 4x, 3 = 8x.

 Enhanced framerate provides faster, tear-free rendering and consistent
 controls and gameplay timing. Ctrl+G cycles ground detail during flight.
 Enhanced flight recordings hold 128 seconds. New enhanced movie saves
 require Enhanced framerate in this slave; original movies remain readable.
